RUMO — LOGIN REAL E MENTOR GRATUITO

O Mentor agora responde no navegador por comandos e sugestões guiadas. Não usa OpenAI, saldo ou assinatura do Mentor. O texto e a navegação funcionam com os dados locais do app; login e voz podem depender de serviços online.

O botão + adiciona referências pessoais temporárias. O assistente não analisa fotos, arquivos ou projetos. Veja MENTOR.md.

PUBLICAÇÃO
Use o repositório Git conectado à hospedagem ou uma CLI com suporte a funções. Netlify Drop sozinho não publica o backend de autenticação. A Netlify estava com novas publicações pausadas na última conferência; este pacote não comprova atualização do endereço publicado.

CONFIGURAÇÃO
Mantenha APP_ORIGIN, SUPABASE_URL e SUPABASE_PUBLISHABLE_KEY no servidor. As antigas chaves de IA e de créditos não são usadas pela conversa gratuita. Nunca coloque segredos no HTML, repositório ou ZIP.

PAGAMENTOS
A tela de compra foi retirada, e novos pedidos são bloqueados no servidor. Os dados privados anteriores não foram apagados; esta mudança não transfere nem devolve dinheiro.

A prévia sem senha usa conta fictícia e é um arquivo separado. O app deste ZIP mantém login real.

CLOUDFLARE
Esta versão também inclui a adaptação para Cloudflare Pages. Veja CLOUDFLARE.md: build node scripts/build-cloudflare.cjs, saída cloudflare-dist. O login usa o mesmo projeto Supabase. Nenhuma mudança de domínio ou DNS foi realizada.
